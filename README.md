# Tap Tap Fruit Pop — Web/PWA

Upload the contents of this folder to any HTTPS static web host.

Main file: `index.html`

The game saves each player's level/high score locally in their browser using localStorage. No server/database is required for the current version.

The included service worker enables offline caching after the first visit. A PWA install option is available in browsers that support installation.

Recommended publishing options:
- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

For a custom domain, point the domain at the selected host.
